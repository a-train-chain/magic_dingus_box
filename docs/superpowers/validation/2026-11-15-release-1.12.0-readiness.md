**Open decision from #14:** should the Content Manager refuse Reconfigure while a movie or game is playing? #14 recommends yes. The cost is that a kiosk stopped mid-playback leaves Reconfigure blocked until the kiosk restarts or the box reboots.

**Release risks to keep in view:**
- **#17 changes two installable units** (`gluetun-cascade-restart.service`, `magic-dingus-services.service`). Per CLAUDE.md "System units converge", a release that changes a unit must stay safe for boxes on v1.10.0 or earlier that reach it in one hop. G2 starts from v1.9.14, a pre-converge tree, and is the test for this.
- **The kiosk-only C++** (`main.cpp`, the renderers, `gst_renderer.cpp`) is compiled for real only by CI's `kiosk-build` job and on a Pi. It has been built and run on magicpi5, never on a Pi 4B.
