# Marquee v1.6.4 — Overlays and Input Grammar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship four UX additions to the Marquee Media Browser as v1.6.4: Discover-style filter overlay (Popular + TopRated), Search keyboard↔grid focus toggle, BTN2=exit-to-kiosk with confirm modal, and rotary-press playback overlay with similar-films strip + quick-add.

**Architecture:** Reuse the slide-in overlay primitive from v1.6.3 LibraryScreen for the new Discover filter overlay. New mb_exit_modal component sits above all MB screens, dispatched from main.cpp. PlaybackScreen gets its own overlay state machine + background pre-fetch of TMDB similar-films. AppState::DisplaySettings gains 12 new persisted fields (6 per Popular/TopRated tab).

**Tech Stack:** C++17, OpenGL ES 3.0 immediate-mode renderer, JsonCpp settings persistence, libcurl + jsoncpp for TMDB/Radarr clients, std::thread for pre-fetch.

**Spec:** [docs/superpowers/specs/2026-04-30-marquee-v1.6.4-overlays-and-input-grammar-design.md](../specs/2026-04-30-marquee-v1.6.4-overlays-and-input-grammar-design.md)

**Verification model:** No unit tests for the UI layer (project precedent). Each task verifies via `cmake --build build` from `magic_dingus_box_cpp/`. The release task adds a Pi smoke-test step.

**Release strategy:** v1.6.3 is unreleased (committed but not tagged/pushed). v1.6.4 absorbs the v1.6.3 CHANGELOG bullets (rename header to v1.6.4 + append new bullets). Single release tag.

```cpp
std::string TmdbClient::build_discover_url(const std::string& api_key,
                                            const DiscoverFilter& filter,
                                            int page) {
    std::ostringstream oss;
    oss << "https://api.themoviedb.org/3/discover/movie"
        << "?api_key=" << curl_easy_escape_str(api_key)
        << "&include_adult=false"
        << "&language=en-US"
        << "&page=" << page
        << "&sort_by=" << curl_easy_escape_str(filter.sort_by);

    if (!filter.genre_ids.empty()) {
        oss << "&with_genres=";
        for (size_t i = 0; i < filter.genre_ids.size(); ++i) {
            if (i > 0) oss << "%2C";
            oss << filter.genre_ids[i];
        }
    }
    if (filter.primary_release_year_gte) {
        oss << "&primary_release_date.gte=" << *filter.primary_release_year_gte << "-01-01";
    }
    if (filter.primary_release_year_lte) {
        oss << "&primary_release_date.lte=" << *filter.primary_release_year_lte << "-12-31";
    }
    if (filter.vote_average_gte) {
        oss << "&vote_average.gte=" << *filter.vote_average_gte;
    }
    if (filter.vote_count_gte) {
        oss << "&vote_count.gte=" << *filter.vote_count_gte;
    }
    if (filter.with_runtime_gte) {
        oss << "&with_runtime.gte=" << *filter.with_runtime_gte;
    }
    if (filter.with_runtime_lte) {
        oss << "&with_runtime.lte=" << *filter.with_runtime_lte;
    }
    if (filter.with_original_language) {
        oss << "&with_original_language=" << curl_easy_escape_str(*filter.with_original_language);
    }
    return oss.str();
}
```

```cpp
#pragma once

#include <chrono>
#include <cstdint>
#include <string>
#include <vector>

namespace ui { class Renderer; }
namespace media_browser { struct TmdbSearchHit; }

namespace media_browser::ui {

// Identifies which underlying tab's filter state this overlay edits.
enum class FilterTabKind {
    Popular,
    TopRated,
};

// View-level snapshot of the per-tab filter state. Consumers (BrowseScreen)
// own the storage in DisplaySettings; this struct is a transient view that
// the overlay reads from and writes back to on commit.
struct FilterState {
    uint32_t genre_mask = 0;
    int decade = 0;       // matches MbDecade enum value
    int min_rating = 0;   // matches MbMinRating enum value
    int runtime = 0;      // matches MbRuntime enum value
    int language = 0;     // matches MbLanguage enum value
    int sort = 0;         // matches MbDiscoverSort enum value
};

class FilterOverlay {
public:
    enum class State {
        Closed,
        SlidingIn,
        Open,
        SlidingOut,
    };

    FilterOverlay();

    // Begin opening the overlay. No-op if already open or sliding in.
    void open(FilterTabKind tab, const FilterState& current);

    // Begin closing the overlay. No-op if already closed or sliding out.
    void close();

    bool is_visible() const { return state_ != State::Closed; }
    bool is_input_active() const { return state_ == State::Open; }

    // Per-frame animation tick. Call from screen's tick() / before render().
    void tick();

    // Input handlers. Return true if the input was consumed.
    bool on_rotate(int delta);    // negative = up/prev, positive = down/next
    bool on_select();              // rotary press → commit current row's value
    bool on_btn4_close();          // BTN4 → start close animation

    // Commits go through this callback. The overlay knows when a value
    // changes (caller's commit sets the new state and triggers a refetch).
    using CommitCallback = std::function<void(const FilterState&, FilterTabKind)>;
    void set_on_commit(CommitCallback cb) { on_commit_ = std::move(cb); }

    // Render the overlay panel. Caller is responsible for screen geometry.
    void render(::ui::Renderer& r, int screen_w, int screen_h);

    // Compute current panel left X (for slide animation).
    int compute_panel_left_x(int screen_w) const;

private:
    State state_ = State::Closed;
    std::chrono::steady_clock::time_point anim_started_at_;

    FilterTabKind tab_ = FilterTabKind::Popular;
    FilterState working_;       // edits in flight before commit
    int focus_row_ = 0;         // 0..kFocusableRowCount-1

    CommitCallback on_commit_;

    static constexpr int kFocusableRowCount = 7;  // 6 filters + Reset
    static constexpr int kSlideInMs = 200;
    static constexpr int kSlideOutMs = 150;
    static constexpr int kPanelWidthPx = 380;

    void render_genre_row(::ui::Renderer& r, int x, int y);
    void render_value_row(::ui::Renderer& r, int x, int y, const std::string& label,
                          const std::vector<std::string>& values, int selected_index);
    void render_reset_row(::ui::Renderer& r, int x, int y);
};

}  // namespace media_browser::ui
```

```cpp
FilterOverlay::FilterOverlay() = default;

void FilterOverlay::open(FilterTabKind tab, const FilterState& current) {
    if (state_ == State::Open || state_ == State::SlidingIn) return;
    tab_ = tab;
    working_ = current;
    focus_row_ = 0;
    state_ = State::SlidingIn;
    anim_started_at_ = std::chrono::steady_clock::now();
}

void FilterOverlay::close() {
    if (state_ == State::Closed || state_ == State::SlidingOut) return;
    state_ = State::SlidingOut;
    anim_started_at_ = std::chrono::steady_clock::now();
}

void FilterOverlay::tick() {
    using namespace std::chrono;
    if (state_ == State::SlidingIn) {
        auto elapsed = duration_cast<milliseconds>(steady_clock::now() - anim_started_at_).count();
        if (elapsed >= kSlideInMs) state_ = State::Open;
    } else if (state_ == State::SlidingOut) {
        auto elapsed = duration_cast<milliseconds>(steady_clock::now() - anim_started_at_).count();
        if (elapsed >= kSlideOutMs) state_ = State::Closed;
    }
}

int FilterOverlay::compute_panel_left_x(int /*screen_w*/) const {
    using namespace std::chrono;
    if (state_ == State::Closed) return -kPanelWidthPx;
    if (state_ == State::Open)   return kPanelLeftMarginPx;
    auto elapsed = duration_cast<milliseconds>(steady_clock::now() - anim_started_at_).count();
    if (state_ == State::SlidingIn) {
        float t = std::clamp(static_cast<float>(elapsed) / kSlideInMs, 0.0f, 1.0f);
        float eased = ease_out_cubic(t);
        return static_cast<int>(-kPanelWidthPx + eased * kPanelWidthPx);
    } else {  // SlidingOut
        float t = std::clamp(static_cast<float>(elapsed) / kSlideOutMs, 0.0f, 1.0f);
        float eased = ease_in_cubic(t);
        return static_cast<int>(-eased * kPanelWidthPx);
    }
}

bool FilterOverlay::on_rotate(int delta) {
    if (!is_input_active()) return false;
    if (delta == 0) return true;
    int new_focus = focus_row_ + (delta > 0 ? 1 : -1);
    if (new_focus < 0) new_focus = 0;
    if (new_focus >= kFocusableRowCount) new_focus = kFocusableRowCount - 1;
    focus_row_ = new_focus;
    return true;
}

bool FilterOverlay::on_select() {
    if (!is_input_active()) return false;

    // Cycle the focused row's value forward.
    switch (focus_row_) {
        case 0: {  // Genre — cycle through enabling/disabling each genre bit
            // For genre, SELECT cycles which genre is being toggled.
            // Simpler design: SELECT toggles the "first" unset bit, or clears all if all set.
            // Most useful: cycle through genres one at a time using rotate, SELECT toggles the focused chip.
            // For initial implementation, treat SELECT as "toggle Action only" (bit 0)
            // and let multi-genre chip navigation be a future enhancement.
            // PRACTICAL: cycle through preset combinations:
            //   none -> Action -> Comedy -> Drama -> Horror -> Sci-Fi -> Action+Comedy -> none
            // For simplicity in v1.6.4, SELECT clears mask. Multi-select chip nav lives in genre row's own focus.
            //
            // Simplest compatible behavior: toggle the genre at chip cursor position.
            // (Chip cursor mechanics deferred to follow-up; for v1.6.4 ship a single-genre cycle.)
            uint32_t mask = working_.genre_mask;
            // Find lowest set bit; if none, set bit 0.
            int next = 0;
            if (mask == 0) {
                working_.genre_mask = 1u;  // Action
            } else {
                // Cycle to next genre bit; wrap to clear at the end.
                int bit = __builtin_ctz(mask);
                int nb = bit + 1;
                if (nb >= kNumGenres) {
                    working_.genre_mask = 0;
                } else {
                    working_.genre_mask = (1u << nb);
                }
            }
            break;
        }
        case 1: working_.decade     = (working_.decade + 1)     % kNumDecades; break;
        case 2: working_.min_rating = (working_.min_rating + 1) % kNumRatings; break;
        case 3: working_.runtime    = (working_.runtime + 1)    % kNumRuntimes; break;
        case 4: working_.language   = (working_.language + 1)   % kNumLanguages; break;
        case 5: working_.sort       = (working_.sort + 1)       % kNumSorts; break;
        case 6: {
            // Reset all
            working_ = FilterState{};
            break;
        }
        default: return true;
    }

    if (on_commit_) on_commit_(working_, tab_);
    return true;
}

bool FilterOverlay::on_btn4_close() {
    if (!is_visible()) return false;
    close();
    return true;
}

void FilterOverlay::render(::ui::Renderer& r, int screen_w, int screen_h) {
    if (state_ == State::Closed) return;

    int panel_x = compute_panel_left_x(screen_w);
    int panel_y = kPanelTopMarginPx;
    int panel_w = kPanelWidthPx;
    int panel_h = screen_h - kPanelTopMarginPx - kPanelBottomMarginPx;

    // Panel fill
    r.fill_quad(panel_x, panel_y, panel_w, panel_h, ::ui::theme::bg_lift, 0.96f);
    // Top + bottom + left rules in gold
    r.fill_quad(panel_x, panel_y, panel_w, 2, ::ui::theme::accent, 1.0f);
    r.fill_quad(panel_x, panel_y + panel_h - 2, panel_w, 2, ::ui::theme::accent, 1.0f);
    r.fill_quad(panel_x + panel_w - 2, panel_y, 2, panel_h, ::ui::theme::accent, 1.0f);

    int x = panel_x + kPaddingX;
    int y = panel_y + 32;

    // Heading
    r.draw_text("FILTERS", x, y, ::ui::theme::accent, 22.0f);
    y += 40;

    // Row 0: Genre
    bool focus0 = (focus_row_ == 0);
    if (focus0) chrome::draw_cursor_marker(r, panel_x + 6, y + 12, /*point_right=*/true);
    render_genre_row(r, x, y);
    y += kRowHeightPx;

    // Rows 1-5: value selectors
    auto draw_row = [&](int row_idx, const char* label, const char** values, int n, int selected) {
        bool focus = (focus_row_ == row_idx);
        if (focus) chrome::draw_cursor_marker(r, panel_x + 6, y + 12, /*point_right=*/true);
        std::vector<std::string> vs;
        vs.reserve(n);
        for (int i = 0; i < n; ++i) vs.emplace_back(values[i]);
        render_value_row(r, x, y, label, vs, selected);
        y += kRowHeightPx;
    };

    draw_row(1, "DECADE",     kDecadeLabels,   kNumDecades,   working_.decade);
    draw_row(2, "MIN RATING", kRatingLabels,   kNumRatings,   working_.min_rating);
    draw_row(3, "RUNTIME",    kRuntimeLabels,  kNumRuntimes,  working_.runtime);
    draw_row(4, "LANGUAGE",   kLanguageLabels, kNumLanguages, working_.language);
    draw_row(5, "SORT BY",    kSortLabels,     kNumSorts,     working_.sort);

    // Row 6: Reset
    bool focus6 = (focus_row_ == 6);
    if (focus6) chrome::draw_cursor_marker(r, panel_x + 6, y + 12, /*point_right=*/true);
    render_reset_row(r, x, y);
}

void FilterOverlay::render_genre_row(::ui::Renderer& r, int x, int y) {
    r.draw_text("GENRE", x, y, ::ui::theme::dim, 14.0f);
    int chip_y = y + 18;
    int cx = x;
    int cy = chip_y;
    constexpr int kChipPad = 6;
    constexpr int kChipH = 22;
    for (int i = 0; i < kNumGenres; ++i) {
        bool on = (working_.genre_mask & (1u << i)) != 0;
        int chip_w = static_cast<int>(r.measure_text(kGenres[i].display, 12.0f)) + kChipPad * 2;
        if (cx + chip_w > x + kPanelWidthPx - 2 * kPaddingX) {
            cx = x;
            cy += kChipH + 4;
        }
        if (on) {
            r.fill_quad(cx, cy, chip_w, kChipH, ::ui::theme::accent, 1.0f);
            r.draw_text(kGenres[i].display, cx + kChipPad, cy + 4, ::ui::theme::bg, 12.0f);
        } else {
            r.fill_quad(cx, cy, chip_w, kChipH, ::ui::theme::bg_lift, 0.6f);
            r.draw_text(kGenres[i].display, cx + kChipPad, cy + 4, ::ui::theme::dim, 12.0f);
        }
        cx += chip_w + 4;
    }
}
```

```cpp
void PlaybackOverlay::start_prefetch(::media_browser::TmdbClient& tmdb,
                                      const PlaybackOverlayMovieMeta& meta) {
    if (meta.tmdb_id == 0) {
        meta_ = meta;
        fetch_state_.store(FetchState::Loaded);  // empty similar list
        return;
    }
    if (prefetched_tmdb_id_ == meta.tmdb_id && fetch_state_.load() != FetchState::Idle) {
        return;  // already fetched/fetching this id
    }

    cancel_prefetch();
    if (fetch_thread_.joinable()) fetch_thread_.join();

    meta_ = meta;
    prefetched_tmdb_id_ = meta.tmdb_id;
    cancel_requested_.store(false);
    fetch_state_.store(FetchState::InFlight);
    {
        std::lock_guard<std::mutex> lock(similar_mu_);
        similar_.clear();
    }

    fetch_thread_ = std::thread([this, &tmdb, id = meta.tmdb_id]() {
        auto results = tmdb.get_similar(id, 1);
        if (cancel_requested_.load()) return;
        std::lock_guard<std::mutex> lock(similar_mu_);
        similar_ = std::move(results);
        if (similar_.size() > kMaxSimilar) similar_.resize(kMaxSimilar);
        fetch_state_.store(similar_.empty() ? FetchState::Loaded : FetchState::Loaded);
    });
}

    cancel_requested_.store(true);
}

bool PlaybackOverlay::on_rotate(int delta) {
    if (!open_.load() || delta == 0) return open_.load();

}
```
